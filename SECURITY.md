# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a Vulnerability

This is a solo-maintained project. The safest channel is a
[private vulnerability report](https://github.com/itpoohzhi/model-georouter/security/advisories/new)
(requires a GitHub account) — it stays hidden until a fix is released.

No account? Open a minimal public issue without exploit details and the
maintainer will follow up.

Please include: affected version/commit, impact, and reproduction steps.
There is no fixed SLA, but reports are read promptly.
